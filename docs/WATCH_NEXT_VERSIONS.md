# Watch 1.0.5 client versions

Points in Time 0.4.4 and portable Timecard 0.1.1 reserve distinct component identities for the changed Watch-local tap/sleep adapter linked into every current app. The Timecard model remains 1.0.4; private data formats and grants are unchanged. The immutable Watch 1.0.2 tag tests read a frozen snapshot of the original source manifests rather than future working-tree versions.
